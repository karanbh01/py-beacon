Beacon chart styles

Every part of the default design, open to change

Every setting of beacon.plot's chart design, on sample charts and a table. The charts start in Beacon's default design. Change any setting and they redraw, and the code below the form changes to match. A blue dot marks a setting that differs from the preset you started from. The charts here are drawn in your browser as a sketch of what the library draws, so check a look in Python before relying on it. Charts explains every setting.

The same in code


        

          
Style is the look itself: one value holding every setting. It changes nothing until it's used, and can be saved to a file and loaded again.

          
configure() makes a look the default for every chart drawn afterwards, like use(theme) does today.

          
settings() does the same for one with block only, then puts the previous look back.

          
Keyword arguments on a chart change that chart alone.

        

      

    


    

  


  

    

      
Series colours

      
The default order for lines and other series: nine colours, then black (white in the dark themes) and five greys for lines that set the context rather than lead, such as peers. Orange is gone from the defaults. Each block shows the hex code it is drawn in. A dark block marked "proposed" is a stand-in until its dark-theme colour is chosen.
